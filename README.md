# La Ruleta Decide

## Cómo subirlo a GitHub Pages

1. Creá un repositorio nuevo en GitHub (por ejemplo `la-ruleta-decide`).
2. Subí estos archivos a la raíz del repo: `index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.
3. Andá a **Settings → Pages**, elegí la rama `main` y carpeta `/ (root)`, guardá.
4. En un par de minutos la app queda online en `https://TU-USUARIO.github.io/la-ruleta-decide/`.

## Instalarla

- **Android (Chrome)**: abrí el link, tocá el menú (⋮) → **"Instalar app"** (o puede aparecer el banner de instalación solo). Queda con su ícono como una app más.
- **iPhone (Safari)**: abrí el link **en Safari** (tiene que ser Safari, no Chrome), tocá el botón Compartir (el cuadrado con la flecha) → **"Agregar a inicio"**. Queda con ícono y pantalla completa, sin barra del navegador.

No hace falta VPN ni nada especial en ninguno de los dos casos — alcanza con abrir el link normal una vez que esté publicado en GitHub Pages.

## Antes de usarla esta noche

- Probala vos primero: cargá un par de participantes de prueba, hacé girar la ruleta, y fijate que el festejo y el historial se vean bien en tu celular.
- Todo lo que cargues (participantes, fotos de premios, historial, tema, tamaño de letra) se guarda en el celular de cada persona que la usa, no en un servidor — así que si la van a usar desde el celular de otra persona, van a tener que cargar los participantes ahí también.
